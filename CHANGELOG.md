# Changelog

## 0.1.0 — 2026-11-18
First public release.
- Engine: assistant config, stage graph with hop caps, HTTP tool protocol, injected arguments, no-progress and repeat guards.
- LiveKit voice worker: SIP and browser calls, greeting, fallback LLM, end call, transfer, inactivity prompts, session logs.
- Text runner over any OpenAI-compatible API, plus `pjvoice chat`.
- Control plane: assistants, phone routing, tenant config webhook with last-known-good fallback, text turn endpoint.
- Reference booking tool server with a correctness layer.
- Simulated-caller eval harness and three scenarios.
